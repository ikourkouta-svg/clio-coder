## Built

- Ten typed trace routes, generated OpenAPI, the worker-owned TraceReader adapter, closed public row projections, and receipt field policy.
- Keyset pagination over started_at and run_id, with a 200-row maximum, source/status filters and parameterized search across all five specified fields. A lookahead row determines nextCursor, including exact page-size multiples.
- Run, phases, events, gates, envelopes, processes, receipt and evidence reads. Receipt summary omits output, upstreamResponses, routeDecision, briefing, and steering before RPC; the service also enforces that public policy. Full payload is fetched only on request. Missing and corrupt sidecars remain local absences.
- A cached read-only TraceReader, schema recheck, replacement detection using device/inode, recovery on schema/I/O errors, and containment checks on database and sidecar realpaths. Paths never appear in trace status or storage errors.
- Resource SSE polls the reads worker every 500 ms, streams rowids in order, honors Last-Event-ID, and closes after two idle terminal polls. Token query authentication is restricted to declared SSE routes.
- Trace history and run pages with live state, phase selection/waterfall/tool spans, phase facts, truthful tokens and cost, event summaries and payload disclosure, truncation notices, gate checks/violations, processes, envelopes, receipt sections, and explicit receipt/evidence disagreement. The client adopts the server Date once and uses the trace-viewer's pinned formatting.
- Strict integer query handling: tests exposed TypeBox truncating decimal strings; fractional limits/cursors now fail before conversion. Known API paths with unsupported verbs return 405; HEAD is supported for reads.
