## Built

- Recent workspaces with absolute-directory validation, realpath canonicalization, stable path-derived identities, and a 40-entry app-owned recent list.
- Durable session history through listSessionsForCwd in the reads worker, with path preflight and a closed public projection. No child is needed to list history. Opening/loading binds one ACP child to one canonical workspace and session.
- One process chokepoint resolving CLIO_CODER_WEB_CLI (absolute existing file), checkout dist/cli/index.js, then PATH. ACP transport, safe environment handling and owned-process termination remain the root seam's responsibility.
- Supervisor with four-session admission, child ownership records persisted before initialize, the full seven-kind event opt-in, create/load/prompt/close, and prompt cancellation during graceful teardown. Idempotency covers workspaces, session creation/load/close and turn admission, including concurrent duplicate requests.
- App-only state serialization uses immutable contender identities and a filesystem bakery lock so independent servers cannot lose one another's updates or remove a replacement lock by mistake. A three-process test verifies all 45 writes survive.
- Startup reconciliation checks both owner and child birth identities. Only a recorded child of a proven-dead owner is a signal candidate. Recovered snapshots transition unknown to closed; stale PID-reuse records are dropped without signalling the unrelated process. Session-ledger bytes are never edited by reconciliation.
- Shared server/client turn reducer and revision buffer: user/text/thought/tool/notice items, replay origins, agent attribution, tool kind/status/locations/input/result, the five usage fields, bounded text/timeline/turn summaries, and exactly-once application across held snapshots. Root usage metadata's additional total/cost fields are projected away for the five-field UI contract.
- Workspace, session list, conversation and saved-session load pages. The S3 permission handler always selects a reject option or cancelled outcome, records permission.rejected with reason no-ui, and never executes implicitly. Approval/cancel/settings/fleet controls remain S4.
